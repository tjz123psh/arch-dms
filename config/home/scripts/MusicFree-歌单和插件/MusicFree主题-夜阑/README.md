# 夜阑 · MusicFree 本地主题

一句话：把 MusicFree 换成和你 niri + Noctalia 桌面同款的深色玻璃皮肤，背景是一整套会呼吸的动态夜景。

风格定位：**「融蕴 Noctalia 极夜色盘的静谧毛玻璃皮肤，以微风落瓣与月华光带雕琢深邃声景的暗夜沉浸主题」**
（Material You 的深夜蓝打底 + Noctalia 式玻璃胶囊界面 + 空气感粒子）。
背景由三级景深花瓣、光学弥散光斑、反重力星尘与极光丝带组成（v2.0.1 稳态约 535 个活动元素），
并有周期性的阵风 / 掠镜 / 流星事件。

---

## 一、装上它

**方式 A（最省事）**：把上一级目录里的 `夜阑.mftheme` 直接**拖进 MusicFree 窗口**，会自动安装并切换。

**方式 B**：主题 → 本地主题 → 左上角「+」→ 选 `夜阑.mftheme` → 安装。

**方式 C（已经帮你做了）**：主题包已经解好放在
`~/.config/MusicFree/musicfree-themepacks/Hy9nT4kQ2mZx7LpR5wVc3-noctalia-night/`
（目录名固定取自 config.json 的 id；重复执行 `build.sh --install` 是覆盖，不会在列表里堆出多份）。
本地主题列表是 App 启动时读一次并缓存的，所以**重启一次 MusicFree**，进「主题 → 本地主题」就能看到「夜阑」，点一下即应用。

> 想卸载：在主题页删掉它，或直接删上面那个目录。
>
> ⚠️ 方式 A / B 都会**再解压出一份新的副本**（MusicFree 每次安装都用随机目录名），于是「本地主题」里会出现两个「夜阑」。
> 已经装好了就别再拖一次；真要重装，先把旧的删掉。

## 二、它长什么样

### 层次（自下而上）

| 层 | 作用 |
| --- | --- |
| 底色 + 极光 | 三团极慢呼吸的色板光晕打底 |
| 远景壁纸 | 用一张 240×135 的小模糊图放大铺满，220 秒漂移一次（便宜一个数量级的假虚化） |
| 近景壁纸 | 当前壁纸的双色调压暗版，150 秒缓慢漂移 |
| 辉光 | 光源方向的 screen 叠加 + 人物剪影位置的轮廓光（合并成一层） |
| 压暗层 | 只护壁纸，保证浅灰文字的对比度 |
| canvas 粒子 | 见下表 |
| 薄纱 | 盖在粒子之上，顶部/底部更厚，正好护住顶栏与播放条文字 |
| 胶片颗粒 | 256×256 离线噪声、3.2%、1.4 秒步进抖动，同时消掉深色渐变的色阶断层 |
| 暗角 / 昼夜 | 暗角 + 按本地时间做 ±0.10 以内的极轻色温偏移（黄昏偏暖、深夜偏冷） |

### 粒子与事件（v3 加料版）

> **下表列的是 `DENSITY = 1.0` 的基准值**，实际数量 = 表值 × DENSITY（各类另有下限保护）。
> 默认 `DENSITY = 1.2` 实测稳态 **535** 个（花瓣 + 星尘 + 微光 + 星空 + 光斑 + 星芒 + 萤火 + 叶片 + 丝带 + 光带），
> 另有浮沫 26、涟漪 4、涡旋 2 不在这个口径里 —— 全算上是 567 个；阵风/花吹雪会让花瓣短暂冲到约 551。
> 想更热闹就把 DENSITY 往上调（2.0 是「花吹雪」档）；0.6 是省电档，但各类有下限兜底，实测落在约 51%（535 → 273）而不是正好六成。

| 元素 | 数量 | 说明 |
| --- | --- | --- |
| 前景大虚化花瓣 | 5 | 45~75px，α0.18~0.30，大散焦精灵；只走左右两侧走廊，不挡歌名 |
| 中景花瓣 | 16 | 14~26px，α0.55~0.78，双轴翻滚 + 顺风倾斜；含约 1/3 染色瓣（浅蓝紫 / 樱粉 / 暖米白） |
| 远景细碎花屑 | 28 | 3~6px，撑「空气介质感」 |
| 上浮星尘 | 150 | 0.8~2px，反重力上浮 |
| 下沉微光 | 110 | 0.8~1.8px 缓慢沉降 —— 与星尘构成**双向对流**，空间立刻有体积 |
| 静态星空 | 80 | 不动，只各自呼吸闪烁；作为「不动的参照系」，前面的飞掠才有速度感 |
| 光学弥散光斑 | 11 | 60~160px，中心通透 / 边缘聚光 / 次色色散；75% 落在两侧 |
| 星芒 | 18 | 平时暗淡，呼吸到峰值才亮（堆多了会像抽卡特效） |
| 萤火 / 灵光球 | 18 | 唯一不受重力约束的元素：二维曲线游走 + 呼吸明灭，身后留星屑 |
| 叶片 | 5 | 细长、翻滚快、有质量感，作为稀有重量锚点 |
| 顶部极光帘幕 | 2 | 只在顶部 22% 区域缓慢起伏 |
| 体积光带 | 3 | 斜向，与气流走廊平行，常态可见 |
| 播放条上沿浮沫 | 26 | 贴底水平浮动，给画面一个「落地感」 |

**让运动不再是「直线挂面」的两套机制**：

- **涡旋力场**：2 个半径约 200~260px 的隐形缓动涡旋，给经过的花瓣/星尘/叶片一个切向加速度 ——
  轨迹会拐弯、会逗留、会回旋，这是「看起来像活的」最关键的一笔。
- **花粉尾迹**：花瓣与萤火飞过时，会以每秒几次的概率就地丢下寿命 0.4~0.7 秒、原地淡出的微星屑。

**事件**（错峰触发，不扎堆）：

- **阵风**：每 14~24 秒一次、持续 3.5~4.8 秒，带冲量与阻尼包络；全场联动 —— 花瓣顺风倾斜、星尘被卷起、
  叶片加速翻滚、光斑推移、光带亮起 40% 后平滑回落，同时从迎风侧涌入一批花瓣。
- **花吹雪**：每 9~20 秒从某处飘出一小簇 4~8 片花瓣，速度方向高度相关 —— 读起来是「一阵花瓣雨」而不是零散点。
- **掠镜巨瓣**：8~25 秒一次，一片大散焦花瓣贴着镜头斜掠而过。
- **伴生双发流星**：20~35 秒一次；主星划过约 0.2 秒后，斜后方跟一颗偏粉紫的细伴星。
- **底部涟漪**：每 12~20 秒从下方扩散一圈极淡的环，给播放器一点「声波/水月」的通感。
- **底部消融**：粒子落到画面最底前线性淡出，不会撞在播放条上。

### 界面

顶栏渐变发丝线 + 玻璃搜索胶囊（含焦点环）、标签 hover/选中的柔光胶囊、侧栏发光选中胶囊 + 右缘渐隐描边、
播放条强调色顶边 + 播放键玻璃圆顶 + 发光进度条与播放头、弹层/Toast 玻璃亮边、渐变滚动条、表头渐变底线。
动效都在 200~300ms，没有循环动画。

### 实测数字

- **对比度**（`tools/contrast.py` 量纯背景帧，口径写在脚本头部）：
  正文 `#e0e2e8` p50/p95/p99/p99.5 = **12.3 / 8.7 / 7.3 / 7.1:1**；
  艺人行（应用真实口径 = 文字色 @80% 不透明）**8.4 / 6.2 / 5.4 / 5.2:1**；
  低于 4.5:1 的像素占 0.04% / 0.13%（单帧快照，逐帧有波动；数字与随包的 `tools/ref-bg-942x1012.png` 一一对应）。
- **性能**：约 540 个元素下 canvas 平均 **3.3ms/帧**（其中点光源泛光约 2.3ms；把 `BLOOM_STRENGTH` 设为 0 就是 1.0ms），
  峰值 5.6ms —— 相对 30fps 的 33ms 预算仍有约 10 倍余量。30fps 节流、切后台停帧、
  系统开「减少动态效果」时只画一帧静态构图；动画层上没有逐帧 `filter`，
  `mix-blend-mode` 只有 2 层（辉光 screen、颗粒 soft-light）。
  （两个性能旋钮：`BLOOM_STRENGTH` 默认 0.38、`DENSITY` 默认 1.2，设 0 即关闭对应效果；
  另外引擎自带保护：连续 90 帧超过 46ms 会自动把密度降到 0.6。）
- **底图配方跨壁纸稳定**：先双色调、再压中间调（gamma 0.82）+ 提彩度 ×1.5；
  实测雪景 / 逆光 / 深色三类壁纸出图亮度都落在 0.12~0.19、饱和度约 0.30。

## 三、换了壁纸 / 想改

```bash
cd "MusicFree主题-夜阑"
./build.sh              # 取 Noctalia 当前色板 → 同步 index.css + app.html → 按当前壁纸重生成底图 → 打包
./build.sh --install    # 顺便覆盖安装到 MusicFree 本地主题目录
./build.sh --theme-dir /tmp/副本   # 对另一份副本试跑（防止误触交付目录；试验/CI 用这个）
```

产物写在上一级目录：**`<主题名>-v<版本>.mftheme`** —— 版本号取自 `config.json` 的 `version` 字段，由 `tools/rebuild.py` 自动拼进文件名，不用记着手动改；发新版只要 bump 一次 `version`，旧包会按版本各留一份（例如现在同时有 `夜阑-v1.0.0.mftheme` 与 `夜阑-v2.0.0.mftheme`）。

手改的话：

| 想改什么 | 改哪 |
| --- | --- |
| 主题名 / 作者 / 描述 | `config.json`（改完重新打包） |
| 颜色 | `index.css` 里 `PALETTE-START`…`PALETTE-END` 之间（这段会被 build.sh 覆盖） |
| 动效配色 | `iframes/app.html` 里也有一段同名 PALETTE 段，build.sh 会一起重写，保证界面与粒子同源 |
| 毛玻璃、发丝线、胶囊等界面细节 | `index.css` 下半部分（`--yl*` 玻璃工具箱变量全在那里，由色板 color-mix 派生） |
| 粒子数量 / 速度 / 事件节奏 | `iframes/app.html` 脚本里 `populate()` 的密度公式与 gust / flyby / meteor 的重置函数 |
| 列表缩略图 | `imgs/preview.jpg` |
| 背景底图 | `imgs/bg.jpg`（近景）与 `imgs/bg-soft.jpg`（远景模糊，build.sh 一起重生成） |

调试小工具（控制台可用）：`window.__nightGust()` 立刻来一阵风、
`window.__nightFlyby()` 放一片掠镜巨瓣、`window.__nightStats()` 看当前粒子数与帧耗时。

## 五、它是怎么被 MusicFree 加载的（给排查用）

从 MusicFree 0.0.8 的主进程代码里确认的契约：

1. 主题包就是一个 zip（后缀 `.mftheme`），**根目录**必须同时有 `config.json` 和 `index.css`；
2. 安装 = 解压到 `~/.config/MusicFree/musicfree-themepacks/<随机12位>/`；
3. `index.css` 被塞进 index.html 里的 `<style id="themepack-node">`；
4. CSS 和 iframe HTML 里的 `@/` 会被替换成 `file://<主题目录>/`；
5. `config.iframe` 支持 6 个槽位：app / header / body / music-bar / side-bar / page，
   会被 prepend 到对应的 `.<槽位>-container` 里（应用自带 `iframe{position:absolute;width:100%;height:100%;pointer-events:none}`）。
   本主题只用 `app` 这一个，即整窗背景。

> ⚠️ 主题样式表在 `<head>` 里，而应用自己的样式是运行时注入、排在它后面，
> 所以**同优先级的规则会被应用盖掉** —— 本主题所有变量和关键覆盖都带 `!important`，改的时候别删。

## 六、已知局限（别踩）

1. **主题不会自动生效，且尚未在真实 App 里验证过观感**：MusicFree 启动时套的是 localStorage 里记着的那个主题
   （原来是「雨季」），所以装完必须自己在「主题 → 本地主题」里点一次「夜阑」。
   已完成验证：加载契约、安装副本一致性、动效在动、reduced-motion 静态帧、帧耗时、对比度（均由独立验证员复跑）；
   **未验证**：真实 App 里父窗口与背景 iframe 的层叠/遮挡观感 —— 那要你点一次才算数。
2. **弹层毛玻璃靠 id 挂载，panel 那半边多半看不出磨砂**：容器 id 是 components--modal-base-container / components--panel-base-container，
   主题给它们加了 `backdrop-filter`。但应用里 modal 组件的 withBlur 默认 true、panel 默认 false，
   所以「播放列表 / 评论」这类侧栏面板实际只会看到半透明遮罩而不是磨砂 —— 这是应用调用方的选择，主题补不了。
3. **换壁纸后必须重跑 build.sh**：色板与底图都不会自己变。取不到壁纸时脚本报错退出（exit 2），
   不会给你打一个「新配色 + 旧底图」的错配包；确要用旧底图需显式加 `--allow-stale-bg`。
4. **粒子与文字的关系**：花瓣/光斑画在压暗层之上（`#scrim` → `#fx`），不会被压暗层衰减；
   实测低于 4.5:1 的像素占 0.04%（正文）/ 0.13%（艺人行）——口径与 §二 完全一致；
   最坏的单像素就是正好被花瓣核盖住的那几个点。
   想更稳就调低 `iframes/app.html` 里各 tier 的 `p.alpha`，或把 `#fx` 挪到 `#scrim` 之前。
5. **只用了一个 iframe 槽位**（app）：动效是整窗背景。想给顶栏/播放条单独加动画，可以在 config.json 的
   iframe 里加 header / music-bar 等槽位，指向另外的 HTML。

## 七、这一版是怎么做出来的（过程留档）

- **格式与契约**：直接读 MusicFree 0.0.8 打包后的主进程 / 预加载代码，确认主题包格式、注入点、别名替换规则与 6 个 iframe 槽位；
  再用脚本模拟它的 loadThemePack() / selectTheme() 做机器可校验的验收。
- **配色**：从本机 Noctalia 生成的 GTK 色板 + starship 色板取值（tools/rebuild.py），界面与粒子的颜色同源，换壁纸一起变。
- **审美设计**：由 Gemini 3.8 做多模态评审（三轮）—— 它看过真实渲染帧后给出景深分级、光斑光学化、
  对角走廊流场、区域密度避让等具体参数；其中「总粒子数压在 80 以内、靠尺寸跨度而非数量堆丰富度」这条直接改变了实现方向。
- **独立验证**：另有两名队友分别做契约 / 渲染 / 性能 / 对比度验证与对抗式代码审查，交付前发现的问题已全部修复并复跑。
